## Project Overview
This is a web-based AI application built using **Streamlit** and **TensorFlow / Keras** that can classify waste materials into 8 categories: Battery, Biological, Cardboard, Glass, Metal, Paper, Plastic, and Shoes. It uses **Transfer Learning (MobileNetV2)** for image classification.
